# 首页 UI 改版：布局 B + 风格 1 夜航手账

日期：2026-08-14  
状态：已选定，待实现  
范围：首页 Home 主界面（含 BottomCard / FAB / 顶栏图标）；不改业务逻辑与路由

## 1. 目标

- 强化「点亮新地方」为拇指热区主操作（P0）
- 地图沉浸：统计上浮变轻量，底栏改成「筛选 + 通栏主按钮」
- 统一为「夜航手账」视觉：深色、线框图标、金色只给主 CTA，收敛 emoji

## 2. 信息 / 行为优先级

| 优先级 | 能力 | 落点 |
| --- | --- | --- |
| P0 | 点亮新地方 | 底栏通栏主按钮 |
| P1 | 地图浏览 + 筛选谁 | 全屏地图 + 底栏筛选 chips |
| P2 | 纪念卡 / 邀请 | 右上线框图标（相机、设置内邀请） |
| P3 | 标记包等装饰 | 设置抽屉 |

长按地图加点亮仍保留，作为快捷路径。

## 3. 布局 B（动作条）

### 3.1 结构

```
┌─────────────────────────┐
│ 标题 + 轻量统计 chips    │  相机  设置   ← 顶区
│                         │
│         地图             │
│                         │
│  ┌───────────────────┐  │
│  │ 筛选 chips         │  │
│  │ [  点亮新地方  ]   │  │  ← 底栏动作条
│  └───────────────────┘  │
│  同步状态（细字）         │
└─────────────────────────┘
```

### 3.2 相对现状的变化

- **删除**悬空 FAB「＋ 点亮新地方」
- **压缩**底部大卡片：去掉大标题区主导视觉 / handle / 大 ♥；标题与统计移到左上轻量区
- **底栏**：筛选一行 + 通栏金色主按钮「点亮新地方」
- **顶栏**：📷 / ⚙ 改为统一线框 SVG icon（aria-label 保留）

### 3.3 空态

无足迹时：底栏主按钮上方一行提示「搜索或长按地图，点亮第一个地方」；不另占大卡片。

## 4. 风格 1 · 夜航手账

### 4.1 色板（延续并收敛）

- 背景 / 地图：`#121826` 系
- 卡片 / 动作条：半透明深色 + 弱模糊，描边 `rgba(245,247,251,0.12)`
- 主 CTA：金色 `#ffd278`（文字深色）；**仅主按钮与极少量 kicker 用金**
- 筛选选中：弱金边或浅金底，避免四色争抢
- 兔子粉 / 啾啾蓝：仅在对应 filter pressed 时轻微着色，默认中性

### 4.2 图标

- 统一 **1.5px stroke** 线框：心、加号圆、相机快门、齿轮/设置
- 首页主路径 **不再使用 emoji** 作为按钮内容（相机、设置、FAB 加号）
- 筛选文案可保留「兔子 / 啾啾 / 一起」，不强制加动物 emoji

### 4.3 字体与模块

- 标题：保留 Songti 小标题（顶区），字号下调
- UI：无衬线；主按钮字重偏粗
- 圆角：动作条 / 按钮 16–20；chips 胶囊
